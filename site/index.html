DSH 侧边栏 · 隐私政策

生效日期：2026-10-08 · 适用于 Microsoft Edge 扩展「DSH 侧边栏」（DSH Sidebar）

1. 一句话结论

本扩展不收集、不存储、不传输任何个人信息，也不包含分析、广告或追踪代码。 它唯一访问的网络地址是你自己电脑上的回环地址（127.0.0.1 / localhost）。

2. 扩展做什么

本扩展提供一个 Edge 侧边栏面板，用来打开并聚焦你本机运行的 DeepSeek Harness（dsh web）界面。 它不代理、不修改、不拦截该界面的任何数据。

3. 处理哪些数据，以及为什么

数据存放位置用途是否外发
DSH 服务地址（如 http://127.0.0.1:19387） 仅本机 chrome.storage.local 记住要连接的本机服务 否
一次性启动 token 仅本机 chrome.storage.local，兑换成功后立即清除 完成 DSH 自身的登录态交换 否；只发送给 127.0.0.1 上的 DSH
承载窗口的 id 与窗口尺寸 仅本机 chrome.storage.local 重新打开时复用窗口、保持侧栏形状 否

以上均以 chrome.storage.local 保存在你的设备上，不使用云端同步 （扩展未申请 storage.sync，也未申请 cookies、webRequest、 history、bookmarks 等权限）。

4. 网络访问范围

扩展的 host_permissions 只包含 http://127.0.0.1/* 与 http://localhost/*。它：

  • 用该权限探测你本机的 DSH 是否在运行（根据 HTTP 状态码判断，401 亦视为在线）；
  • 除此之外不向任何服务器发起请求，包括扩展开发者自己的服务器（本扩展没有此类服务器）；
  • 不加载、不执行任何远程代码，全部逻辑都打包在扩展内。

5. 与 DSH 自身的关系

扩展会把 DSH 界面作为普通网页打开，因此你在该界面中的所有操作（包括你发送给模型的对话内容） 都直接发生在你的浏览器与你的本机 DSH 服务之间，依据 DeepSeek Harness 自身的隐私实践处理。 本扩展不读取、不记录这些内容。

6. 第三方

不涉及。扩展不含任何第三方 SDK、分析服务、广告网络或数据交易。

7. 儿童隐私

扩展不面向儿童，也不收集任何年龄相关信息。

8. 政策变更

若本政策发生实质变更，将更新本页顶部的生效日期，并在扩展的商店一览中同步说明。

9. 联系方式

如有疑问，请通过扩展商店一览中的“支持”链接提交 issue。

Privacy Policy (English)

Effective date: 2026-10-08 · Applies to the Microsoft Edge extension “DSH Sidebar”.

1. Summary

This extension collects, stores and transmits no personal data. It contains no analytics, advertising or tracking code. The only network address it ever contacts is the loopback address of your own machine (127.0.0.1 / localhost).

2. What it does

It provides an Edge side panel that opens and focuses a locally running DeepSeek Harness (dsh web) UI. It does not proxy, modify or intercept any of that UI's data.

3. Data it handles

DataWhere it livesWhySent off-device?
The DSH server address (e.g. http://127.0.0.1:19387) Local chrome.storage.local only Remember which local server to open No
One-time launch token Local chrome.storage.local; cleared right after it is exchanged Complete DSH's own login handshake No — only to DSH on 127.0.0.1
Hosting window id and bounds Local chrome.storage.local only Reuse the window and keep its panel shape No

Nothing is synced to the cloud: the extension does not request storage.sync, cookies, webRequest, history or bookmarks.

4. Network scope

host_permissions covers only http://127.0.0.1/* and http://localhost/*, used solely to probe whether your local DSH is running (an HTTP 401 also counts as online). No other requests are made, and no remote code is loaded or executed.

5. Relationship to DSH itself

The extension opens the DSH UI as an ordinary web page. Everything you do there — including the prompts you send to a model — happens directly between your browser and your own local DSH service, under DSH's own practices. This extension neither reads nor records any of it.

6. Third parties

None. No third-party SDKs, analytics, ad networks or data brokerage.

7. Children

Not directed at children, and no age-related data is collected.

8. Changes

Material changes update the effective date above and the store listing.

9. Contact

Please use the support link on the extension's store listing.
